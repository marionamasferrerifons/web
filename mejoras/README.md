# Mejoras

Backlog d'idees que no formen part del cicle de treball actual però que no es volen perdre. No és una llista de bugs urgents (això va directe a `CHANGELOG.md` un cop resolt) — és un lloc per anotar idees a mitjan/llarg termini.

Format per entrada:

```
## Títol curt de la idea
**Context:** per què sorgeix aquesta idea / quin problema resol.
**Prioritat aproximada:** alta / mitjana / baixa
```

---

(Encara no hi ha cap idea registrada. Afegeix-hi entrades a mesura que sorgeixin.)
